## 1. Purpose and status

This directory preserves the original v1.0 documentation set of Framing Creativity Lab.

These files are retained as historical records of the Lab's earlier documentation framework. They are not the current navigation entry points and must not be confused with the separately maintained v2.0 drafts.

The archived documents remain unchanged in content. Their relocation and versioned filenames provide a clear distinction between the historical baseline and the revised documentation.

## 3. Versioning and authority

The v1.0 documents are preserved for historical reference and traceability.

The v2.0 documents remain separate files at the repository root and are currently marked **Draft for Maintainer Review**.

Archiving the v1.0 files does not, by itself, approve the v2.0 documents or establish their effective date. The approval status and authority of each document must be determined from its own metadata and the applicable maintainer decision.

## 4. Preservation

Historical archive files should not be silently rewritten to reflect later policy decisions.

Corrections to current documentation should be made in the applicable current draft or approved document. A material historical correction, if ever required, must be documented transparently.
